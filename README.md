Rhythm fighting games

==========How to Play========
Player has to attack to the beat. There is a tempo indicator to show when player can attack. 
Game will provide powerups based on the players ability to stay on beat. If player fails
to stay on beat notes will move faster or move at a random direction. 

----------Features-------------

New Movements - Keys
====================
Dash        - LeftShift button
Double Jump - tap space twice
Block       - Right mouse click
Dodge       - q 
stomp       - v

tempo bar to detect player is on beat

q for in game Help screen

Powerups - given in combo attack
==============================================

Slow down beat tempo

Blast enemy when player is close to enemy

Multiple bullets attack - physical item

Temporary invincibility (infinte bullets and health) - physical item

Freeze monsters temporarly - physical item
